Matrix Rain

A fullscreen Matrix-style digital rain effect written in Python + Pygame.

Features

- True fullscreen mode
- Classic green cascading characters (Katakana + Latin + numbers)
- Smooth trailing effect
- After 18 seconds shows the message: **"I hack you"**
- Automatically closes after the message
- Exit anytime by pressing any key or `ESC`

 Requirements

- Python 3.8+
- Pygame
